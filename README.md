# Sobre Mim

Projeto de página pessoal simples construída em HTML5 estruturada em seções sobre trabalho, hobbies e rotina.

## Tecnologias Utilizadas

* **HTML5:** Estruturação de texto e elementos de navegação.

## Estrutura de Branches

Este repositório possui uma organização específica para desenvolvimento de novos recursos:

* **`main` (ou `master`):** Contém a versão base do arquivo `index.html` apenas com o conteúdo principal (`<main>`).
* **`feature/navigation` (ou branch secundária):** Contém a implementação do menu de navegação (`<nav>`) como um recurso em fase de testes/experimento antes de ser integrado à branch principal.

---

## Como Executar o Projeto

1. **Clone o repositório:**
```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio

```


2. **Para visualizar a versão base (sem o menu de navegação):**
Mantenha-se na branch principal:
```bash
git checkout main

```


3. **Para visualizar a versão com a navegação em testes:**
Troque para a branch que contém o recurso de navegação:
```bash
git checkout feature/navigation

```


4. **Abrir a página:**
Basta dar um duplo clique no arquivo `index.html` ou abri-lo diretamente no navegador de sua preferência.
